OBS Phone Cam

Phone camera to OBS over USB — built for quality

Native Camera2 capture on Android, high-bitrate HEVC/H.264 over USB, and a first-class OBS source. Less mush than typical Wi‑Fi webcam apps.

Download v1.0.0 Install guide

3 steps

  1. Install the Windows setup (plugin + FFmpeg + WinUSB helper) and the Android APK.
  2. In OBS, add Phone Cam (USB) and choose Native Max.
  3. Open the app, plug a data USB cable, tap Start.

Requirements

  • Windows 10/11 x64 + OBS Studio 30 or 31
  • Android 8+ phone with USB data cable
  • WinUSB for accessory 18D1:2D00 (installer handles this)

FAQ

No video in OBS? Confirm FFmpeg DLLs sit next to the plugin, then press Request keyframe.

Phone not detected? Open the app first, use a data cable, run the WinUSB helper, unplug/replug.

Wi‑Fi / iPhone? Planned after USB 1.0 — not in this release.
