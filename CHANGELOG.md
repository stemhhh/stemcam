# Changelog

## 1.0.0

### Added
- Android app: Camera2 capture, HEVC/H.264 encode, manual controls, mic audio, USB AOA TX
- OBS plugin (Windows): Phone Cam (USB) source, FFmpeg decode, remote preset/bitrate/torch
- OPCM USB protocol v1 (video + audio + control + stats)
- Quality presets: Native Max, High, Balanced, Low Latency
- ES/EN strings (app + plugin locale)
- Session log export from the Android app
- Alpha pack scripts + Inno Setup installer with WinUSB INF
- Docs: toolchain, smoke QA, device matrix, signing, privacy, FFmpeg notice

### Notes
- First public USB-focused release. WiFi / iPhone / virtual cam are post-1.0.
